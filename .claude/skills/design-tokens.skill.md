# Design Tokens Skill

**Description:** Manage and generate design tokens for consistent UI theming and styling across applications

**Version:** 1.0.0

## Commands

### create-tokens
- **Description:** Create a comprehensive design token system for your project
- **Usage:** `design-tokens create --theme 'light,dark' --platform 'web,mobile'`
- **Action:** Node script `skills/design-tokens.js`

### update-theme
- **Description:** Update theme colors and spacing tokens
- **Usage:** `design-tokens update-theme --primary '#3B82F6' --secondary '#10B981'`
- **Action:** Node script `skills/design-tokens.js`

### export-tokens
- **Description:** Export design tokens to various formats (CSS, JSON, TypeScript)
- **Usage:** `design-tokens export --formats 'css,json,scss'`
- **Action:** Node script `skills/design-tokens.js`
