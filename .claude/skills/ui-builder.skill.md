# UI Builder Skill

**Description:** Build UI components and layouts for the NexusAI frontend

**Version:** 1.0.0

## Commands

### create-hero
- **Description:** Create a hero section with customization options
- **Usage:** `ui-builder create-hero --title 'Your Title' --subtitle 'Your Subtitle'`
- **Action:** Node script `skills/create-hero.js`

### create-model-card
- **Description:** Create a model card component
- **Usage:** `ui-builder create-model-card --name 'Model Name' --provider 'Provider'`
- **Action:** Node script `skills/create-model-card.js`

### create-comparison-table
- **Description:** Create a comparison table component
- **Usage:** `ui-builder create-comparison-table --models 'model1,model2,model3'`
- **Action:** Node script `skills/create-comparison-table.js`

### add-feature
- **Description:** Add a new feature section
- **Usage:** `ui-builder add-feature --type 'stats|newsletter|footer'`
- **Action:** Node script `skills/add-feature.js`
