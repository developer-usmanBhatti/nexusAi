# Responsive Layout Skill

**Description:** Create responsive layouts that work seamlessly across all devices and screen sizes

**Version:** 1.0.0

## Commands

### create-layout
- **Description:** Create a responsive layout with grid and flexbox systems
- **Usage:** `responsive-layout create --type 'grid' --columns '12' --breakpoints 'sm:640,md:768,lg:1024'`
- **Action:** Node script `skills/responsive-layout.js`

### optimize-breakpoints
- **Description:** Optimize responsive breakpoints for your design system
- **Usage:** `responsive-layout optimize-breakpoints --design-system 'tailwind' --devices 'mobile,tablet,desktop'`
- **Action:** Node script `skills/responsive-layout.js`

### test-responsiveness
- **Description:** Test layouts across different screen sizes and devices
- **Usage:** `responsive-layout test --layout-path 'src/components/Layout' --devices 'iphone13,ipad,desktop'`
- **Action:** Node script `skills/responsive-layout.js`
