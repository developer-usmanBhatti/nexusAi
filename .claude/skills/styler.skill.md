# Styler Skill

**Description:** Manage styling and themes for the NexusAI frontend

**Version:** 1.0.0

## Commands

### update-theme
- **Description:** Update the color theme of the app
- **Usage:** `styler update-theme --primary 'indigo' --secondary 'purple'`
- **Action:** Node script `skills/update-theme.js`

### add-animation
- **Description:** Add CSS animations or transitions
- **Usage:** `styler add-animation --type 'hover|scroll|modal'`
- **Action:** Node script `skills/add-animation.js`

### responsive
- **Description:** Make components responsive
- **Usage:** `styler responsive --component 'ComponentName'`
- **Action:** Node script `skills/responsive.js`
